# スケジュール確認アプリ (schedule_check)

バイトのシフト・授業（時間割）・締切をまとめて確認する Flutter アプリです。データは端末内（shared_preferences）に保存されます。

## 機能

- **今日**: 今日の予定、期限切れ・今日が締切・7日以内の締切
- **今週**: 月〜日の週ビュー（前後の週に移動、各日に予定を追加）
- **タスク**: 締切つきタスクの一覧とチェック、残り日数表示
- **取り込み**: メールや連絡文を貼り付け → 日付つきの行を予定/タスク候補にして、確認・修正してから登録
- 予定は「シフト / 授業 / 予定」の種類つき。毎週くり返し（時間割・固定シフト）、終日、場所、メモに対応

## セットアップ

```bash
cd schedule_check
flutter create .        # android/ ios/ web/ などを生成（lib や pubspec は上書きされません）
flutter pub get
flutter test            # 取り込み解析のテスト
flutter run
```

## 取り込みが読める書き方

- 日付: `11/15`、`11月15日`、`2026/11/15`、`2026年11月15日`、`今日` `明日` `明後日`
- 時刻: `10:00`、`10時30分`、範囲 `10:00-18:00` / `10:00〜18:00` / `10時から18時`
- 「締切・提出・期限・まで」を含む行 → タスク、「シフト・バイト・勤務」→ シフト、「授業・講義・ゼミ・実験・休講・補講・試験」→ 授業
- 年のない日付は今年扱い（半年以上前なら来年）。「来週金曜」のような相対表現は未対応

## 構成

```
lib/
  main.dart          アプリ本体・タブ

  ui/                各画面
test/widget_test.dart  解析・繰り返し判定のテスト
```
